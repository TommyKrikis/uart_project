# uart_project

A small repository for UART-related hardware and firmware development.

## Overview
This project contains design files, firmware source, and documentation for UART communication experiments and tools. It is intended as a personal workspace for prototyping UART drivers, testing serial protocols, and capturing notes from hardware tests.

## Contents
- hardware/: PCB designs, schematics, and BOMs
- firmware/: MCU firmware (examples, drivers, tests)
- docs/: notes, test logs, and datasheets

## Usage
1. Open the firmware directory for MCU-specific examples.
2. Build and flash using the toolchain described in the firmware README (e.g., make, cmake, or vendor tools).
3. Use a serial terminal (115200 8N1 by default) to interact with the device.
